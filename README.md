# Arinze's Graduation Weekend 🎓

A single-page invitation and logistics guide for **Arinze Obiezue's graduation weekend** — Stanford GSB, Class of 2026.

🔗 **Live page:** https://heyarinze.github.io/grad/ *(once GitHub Pages is enabled)*

## What's inside

[`index.html`](index.html) is a self-contained static page — no build step, no dependencies — covering everything guests need for the weekend:

- **Schedule of Events** — Black Graduation (Kente Stole Ceremony), GSB Diploma Conferral, Champagne & Sweets Reception, Stanford University Commencement, and the GSB Commencement Luncheon
- **Getting to Campus** — parking, rideshare & drop-off, and key addresses
- **Where to Stay** — nearby hotels, Airbnb/VRBO options (and a spot on my couch)
- **Good to Know** — practical tips for the weekend
- **RSVP** — how to let me know you're coming
- **What We're Celebrating** — three degrees across three continents, the Social Miller Change Leadership Award, and the road that led here

## Viewing locally

Open the file directly in any browser:

```bash
open index.html
```

Or serve it over HTTP:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploying

Hosted with **GitHub Pages**, served from the `main` branch root.
To enable: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
